##### CMD: system upgrade local
  system upgrade local

  Stage a local rootfs image for upgrade (bypasses update server)

  The file must already exist on the device (e.g. copied via SCP).
After staging, run `system upgrade apply` to apply and reboot.

`system upgrade apply` refuses an image whose version is <= the running one. Pass --force-downgrade here to permit it — needed when reinstalling a rebuilt image at the same version, e.g. to verify a fix.

  Usage:
    system upgrade local <path>

  Flags:
        --force-downgrade      Allow an image whose version is <= the running one. Off by default: that check is replay protection against installing older, vulnerable firmware. Use it to reinstall a rebuilt image at an unchanged version.

  Parameters:
    path                 Path to a local .tar.zst rootfs image (e.g. /tmp/nfsensei-1.2.0-x86_64.img) (required)
