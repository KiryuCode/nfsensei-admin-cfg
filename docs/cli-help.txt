nfSensei CLI paradigms
----------------------
This is NOT VyOS, NOT Cisco IOS. Two dispatch styles coexist:

  FLAT commands (typed at the root prompt, take all args inline):
    firewall rule add  |  nat rule add  |  dhcp pool add  |  dns server add
    show <topic>       |  save  commit  discard  rollback  diff

  MODAL contexts (enter, configure, exit):
    interface eth0           -> ip address 192.168.1.1/24 ; mtu 1500 ; exit
    pppoe interface add wan0 -> pppoe interface wan0 ; username "x" ; exit
    routing bgp              -> neighbor 10.0.0.1 remote-as 65001 ; exit

Every change is staged in the CANDIDATE config — `commit` to apply,
`discard` to drop pending changes, `rollback` to revert a committed change.

Inside a modal context type `help` (or `<topic> help` at the root) for the
scope-specific command list.
